# Установка

Это конечно не весь список возможностей, здесь сделан только вывод самой актуальной информации, в виде json массива, по мере возможностей буду дополнять данный функционал

* Для установки нужно запустить composer, который автоматически подгрузит нужные для работы классы
* Запустите через консоль в директории вашего проекта
  ```sh
  composer require visavi/rzd-api
  ```

### Пример работы

Запустите встроенный веб-сервер и откройте главную страницу examples/index.php
```sh
php -S localhost:8000 -t examples
```

Либо запустите любой пример из консоли
```sh
php examples/train_routes.php
```

Сайт rzd.ru принимает запросы только с российских адресов, вне РФ понадобится прокси
```sh
RZD_PROXY=socks5://127.0.0.1:1080 php examples/train_routes.php
```

### Запуск тестов

Основные тесты работают на моках и не обращаются к сети
```sh
vendor/bin/phpunit
```

Тесты группы live проверяют реальные ответы сайта, в обычный прогон не попадают
```sh
RZD_PROXY=socks5://127.0.0.1:1080 vendor/bin/phpunit --group live
```

### Реализованные классы

* Config.php - настройки запросов: язык, таймаут, прокси, userAgent, referer, режим отладки

* Query.php
  * get  - Получает данные, может как принимать данные GET так и отправлять POST (PATCH, PUT, DELETE)
  * run - Вспомогательный метод, запрашивает данные, получает сессию и куки для повторного запроса
  * getRid - Вспомогательный метод, получает уникальный ключ RID (REQUEST_ID)
  
* Api.php
  * trainRoutes - Получение маршрутов в одну точку вместе с данными направления
  * trainRoutesReturn - Получение маршрутов туда-обратно
  * trainCarriages - Получение списка вагонов выбранного поезда
  * trainStationList - Получение списка станций в пути следования выбранного маршрута
  * stationCode - Коды станций с часовым поясом и кодами смежных видов транспорта
